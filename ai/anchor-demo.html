演示一 · 内容右侧的垂直菜单

滚动左侧内容或在右侧点击菜单，高亮都会实时跟随。

什么是锚点组件

锚点组件就是「一列导航 + 若干目标区块」：点击导航跳到对应区块，反过来滚动内容时导航自动高亮当前区块。

以往这一步必须写 JS，用 scroll 事件配合 getBoundingClientRect 反复计算，既费性能又要处理吸顶偏移。

核心只有一个属性

给导航容器加上 scroll-target-group: auto，容器内所有形如 <a href="#id"> 的链接会被浏览器识别为 scroll marker。

浏览器自己维护「谁是当前目标」，然后用 :target-current 伪类把状态交回给 CSS，选择器里写高亮就可以了。

状态跟随滚动

无论是点击链接平滑滚过去，还是手动拖动滚动条、用触控板惯性滚动，高亮都会跟着目标区块走，不需要额外同步。

配合 :target-before 和 :target-after，还能做出"已读进度条"之类的效果，判断链接触发之前还是之后的区块。

兼容与降级

目前 Chrome 140+、Edge 140+、Opera 124+ 已经原生支持，Safari 与 Firefox 还没有。本页检测到不支持时，会监听容器的 scroll，用 getBoundingClientRect 找出当前区块，打上 data-current 作为兜底。

检测方式用特性嗅探 CSS.supports("scroll-target-group: auto")，而不是判断 UA 或浏览器名字：属性将来被改名、被回收，嗅探会自己跟着失效，UA 不会。

两条路径共用同一段高亮样式，业务代码不需要分辨浏览器，也不需要写两套类名。

这也是它比"纯 JS 组件"省心的地方：不支持时唯一的损失是自动高亮，点击跳转本身是原生锚点行为，永远可用，属于安全的渐进增强。

Polyfill 的局限也要知道：它拿的是首次执行时那批区块，如果内容是滚动加载进来的，需要重新收集面板并重算，而原生实现是浏览器自己持续维护的。

等 Safari 补上这块能力，把脚本里那段 if 整块删掉即可，CSS 一行都不用改。

演示二 · 水平排列的选项卡按钮

同一套属性换一种外观：胶囊按钮横排，高亮当作选项卡的选中态来用。

基础用法 选中态 键盘可达 常见问题

基础用法

把链接横排放在内容上方，容器设 scroll-target-group: auto，外观交给普通的 flex 与圆角边框即可。

因为祖先链上的滚动容器会被自动识别，所以这组按钮控制的是下方那个小滚动区域，而不是整个页面。

选中态怎么写

.nav a:target-current 里写背景色和文字色就行，和 :hover、:focus-visible 一样是纯 CSS 状态。

无需额外的 .active 类，也无需在点击时手动移除其他项的高亮，状态永远只与"当前可见的目标"有关。

键盘可达

链接本身就在 tab 序列里，回车即跳转，聚焦样式用 :focus-visible 单独写，语义与原生锚点完全一致。

如果想让它更像 tablist，需要在 JS 里补 role 与方向键逻辑，这部分 CSS 帮不上忙，也不该由 CSS 负责。

常见问题

目标区块记得加 scroll-margin-top，避免固定在顶部的吸顶导航把它遮住。这里之所以看起来刚好对齐，是因为滚动容器自身有内边距。

如果一组菜单对应多个滚动容器，请把菜单拆成多个 scroll-target-group 容器，一个容器只管自己那一组目标。

同一页里有好几组锚点导航时，每组导航各自声明 scroll-target-group 就行，彼此互不干扰；不要把两组链接塞进同一个容器，否则高亮会串。

只有当链接的 href 指向的 id 真实存在时，它才会被识别为 scroll marker；写了 #foo 却没有对应元素，这一项会一直不高亮。

这条属性只负责「谁是当前项」，不改变滚动行为本身。平滑滚动仍然由 scroll-behavior: smooth 控制，两者可以放心组合。

需要更复杂的时序控制时再上 JS：例如「停止滚动 200ms 后才更新高亮」，或者进入视口后延迟切换，这类需求 CSS 不负责，也不该硬塞给它。

  1. 声明即可：导航容器加 scroll-target-group: auto，内部带 #fragment 的 <a> 自动成为 scroll marker，标记与目标的对应关系由浏览器维护。
  2. 高亮交给伪类：:target-current 只匹配「目标正处于视口中」的链接，滚动、点击、惯性滑动都会实时更新，不需要任何滚动监听。
  3. Polyfill 只补状态：不支持时监听容器的 scroll，用 getBoundingClientRect 找出「已经越过容器顶部」的最后一个区块，给对应链接加 data-current，与 :target-current 并列写进同一组选择器。
  4. 想让 URL 干净（可选）：原生锚点跳转必然把 #xxx 写进地址栏，要避免只能拦掉点击、手动 scrollIntoView。这几行 JS 只改「怎么滚过去」，高亮仍由 CSS 负责；href 里的 #fragment 千万别删，删了链接就不再是 scroll marker，高亮直接失效。
