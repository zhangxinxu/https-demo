纯HTML和CSS驱动的任意下拉组件演示页面

三种声明式触发方式，触发元素上一个属性都没有写任何事件逻辑： popovertarget、commandfor、interestfor。 浮层的位置全部交给 CSS 锚点定位。

popover 锚点定位 commandfor interestfor

方式一 · popovertarget

按钮与浮层用 id 绑定，点击开关，按 Esc 或点击空白处自动关闭。

  • CSS CSS 世界2019 年出版
  • 选择器 CSS 选择器世界2020 年出版
  • 新 CSS 新世界2022 年出版

方式二 · commandfor + command

新的 invoker commands 语法：command="show-popover" 显式声明动作，比 popovertarget 更通用。

  • CSS CSS 世界2019 年出版
  • 选择器 CSS 选择器世界2020 年出版
  • 新 CSS 新世界2022 年出版

方式三 · interestfor

悬停或键盘聚焦链接即预展示浮层，移开自动收起，不需要点击。

  1. 零事件逻辑：三种写法都只在触发元素上放属性，加 id 关联目标，开关、light dismiss、Esc 关闭全部由浏览器负责。
  2. 定位交给 CSS：触发元素设 anchor-name，浮层用 position-anchor 加 position-area: bottom span-right 贴住它，JS 一行都不用写。
  3. 按需 polyfill：先检测 "popover" in HTMLElement.prototype、"anchorName" in style、"interestForElement" in HTMLButtonElement.prototype，缺哪个才动态加载哪个，支持的浏览器一个字节都不多下。
  4. 四个 polyfill 各管一段：popover、anchor positioning、invokers（commandfor）、interestfor，检测哪个缺就只加载哪个。invokers-polyfill 支持 show/hide/toggle-popover 与 show-modal，但不负责同步 aria-expanded，无障碍状态仍需自己维护。
