纯CSS实现的跑马灯轮播组件演示案例

一个 overflow-x: auto 的滚动容器，配上 scroll-snap 就是轮播本体； 左右按钮来自 ::scroll-button，索引圆点来自 ::scroll-marker， 没有任何 JS 事件逻辑。

  1. 轮播本体只有滚动：容器 grid-auto-flow: column 加 grid-auto-columns: 100%，每张一屏，scroll-snap-type: x mandatory 负责吸附，手指、触控板、键盘都能操作。
  2. 左右按钮是伪元素：容器声明 ::scroll-button(left/right) 的样式即可，浏览器自动生成按钮元素、自动处理点击滚动和首尾禁用，:disabled 状态也由浏览器维护。
  3. 索引圆点同理：scroll-marker-group: after 让容器生成标记组，每个列表项用自己的 ::scroll-marker 当圆点，:target-current 命中当前项，可以把圆点拉长成胶囊。
  4. 兜底不碰主逻辑：Safari 与 Firefox 目前都不支持这两个伪元素，脚本检测 CSS.supports("selector(::scroll-button(left))") 后，才建真实的按钮和圆点，点击走 scrollTo()，滚动时用 scrollLeft 同步高亮。
  5. 两套样式怎么不重复：外层 .frame 用 width: fit-content 收缩到与轮播同宽，兜底元素才和伪元素落在同一个坐标系；按钮尺寸、偏移、底色、圆点尺寸全部抽成 CSS 变量，两份规则只引用变量，不重复写值。
