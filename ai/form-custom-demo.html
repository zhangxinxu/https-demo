表单控件元素的自定义演示页面

用 appearance: none 抹掉浏览器默认外观，再用伪元素和背景把控件重新画一遍； 色系和本目录其他 demo 保持一致。

一、常规元素

按钮和输入框，直接改 border、background 这些基础属性就行。

这两类元素从 IE 时代就能自定义外观，不需要 appearance，所以归为常规元素。

二、单选框与复选框

默认外观画在浏览器内部的 shadow tree 里，只能先 appearance: none 掀掉，再自己画；开关由复选框派生。

对勾、圆点、滑块都是 ::after 画的，目的是增加一点小动效。 如果是更直白的效果，不使用伪元素，单纯使用background绘制背景也是可以的。

三、范围选择元素

轨道和滑块分别对应 ::-webkit-slider-runnable-track 和 ::-webkit-slider-thumb，Chrome 没有现成的「已填充进度」伪元素。

border-shape 实现滑块组件

60

填充带由 border-shape 画：外轮廓是往左 2000px 的 6px shape()，内轮廓是 circle(50%)，相减只剩带子； 越出边框盒的部分由 overflow: clip 兜底，不用回传进度。轨道上的 clip-path 负责左端那道圆弧，padding-left 把坐标和把手错开。 圆环用 border 描，比径向渐变锐利。不支持 border-shape 的内核回退到 --percent + 轨道渐变。

border-image 实现滑块组件（全兼容，仅直角）

带子由 border-image 画：只有 border-image-outset 能把绘制区域往左撑 2000px 而不改布局， slice 只取左边缘那一片、不开 fill，带子就止步于把手左切点。 轨道两端走直角，左端只用一道矩形 clip-path 把带子挡在边框盒内，可回溯到 Chrome 88。

锚点定位实现滑块组件（Chrome only）

轨道和把手各挂 anchor-name，再用 input::before 绝对定位：left 贴轨道左边、right 贴把手中心， 宽度天然就是「已划过」的长度，不用大带子也不用裁剪；填充条右端藏在抬高的把手底下，anchor-scope 把锚点名限制在各自子树里。

Safari 的 range 不支持伪元素，所以用 @supports not font-tech(color-COLRv1) 认出它，退回 --percent + 轨道渐变。

滑块组件派生评分组件

评星由 range 派生：mask 把输入框镂成 5 颗星，轨道铺满金色，滑块只留 1px 定位点，用它的阴影把右侧盖成灰色。 改 mask-size 和宽高就能得到不同大小、疏密的评分（见第二个）。

四、下拉框选择

支持 appearance: base-select 的内核（如 Chrome 135+）能把下拉面板一起自定义； 不支持的，就只改 select 本身，点开仍是系统默认的下拉。

支持 base-select 时，select 变成一个可控的按钮：箭头是 ::picker-icon， 下拉面板是 ::picker(select)，里面的每一项就是 option， 选中、悬停、禁用都能各给一套样式，展开收起还能用 @starting-style 加个淡入。 箭头用了 mask 取形状、background-color 上色，所以展开时换个颜色就是蓝色箭头。

不支持时只能 appearance: none 后自己补箭头，所以 select 和选项的左右内边距要对得上： 面板里的 option 也是收起状态显示的那一行，两边写一样的 padding，文字才不会跳。

五、日期选择

原生日期浮层各家差别太大（Safari、Firefox 尤其难看），这里用 flatpickr 接管输入框： 输入框外观还是自己写，点开的面板由 flatpickr 来画，各家看到的都是同一套界面。

输入框保持原生 type、加个 readonly，交互交给 flatpickr，日期格式按原生写； 原生日历图标藏掉，右侧图标自己用 background 画（日期给日历、时间给钟表），各家看到的一样； 面板配色直接覆盖 flatpickr 的类名即可。

六、颜色选择

type="color" 的输入框在 appearance: none 之后只剩一块颜色， 用 padding 留出内边距、background-color 做外圈，就能得到正方形色块；点开的取色器还是系统的。

list 指向一个 datalist，取色器里就会多出一排预设色块（Chrome 有效，Firefox 不支持），色值直接取自页面主题色。

里面那块颜色是 ::-webkit-color-swatch，白色描边画在它身上；外圈的灰底和圆角由 input 自己负责。
