表单控件元素的自定义演示页面

用 appearance: none 抹掉浏览器默认外观，再用伪元素和背景把控件重新画一遍； 色系和本目录其他 demo 保持一致。

一、常规元素

按钮和输入框，直接改 border、background 这些基础属性就行。

这两类元素从 IE 时代就能自定义外观，不需要 appearance，所以归为常规元素。

二、单选框与复选框

默认外观画在浏览器内部的 shadow tree 里，只能先 appearance: none 掀掉，再自己画；开关由复选框派生。

对勾、圆点、滑块都是 ::after 画的，目的是增加一点小动效。 如果是更直白的效果，不使用伪元素，单纯使用background绘制背景也是可以的。

三、范围选择元素

轨道和滑块分别对应 ::-webkit-slider-runnable-track 和 ::-webkit-slider-thumb，Chrome 没有现成的「已填充进度」伪元素。

60

左半区的填充交给 border-shape：外轮廓用 shape() 画一条往左 2000px 的 6px 带子， 顺着把手那个圆拐过去，内轮廓就是一个 circle()，两个形状相减只剩填充带； 超出输入框的部分由 overflow: hidden 裁掉，不用回传进度。 不支持 border-shape 的内核，由页面底部的几行 JS 把进度写进 --percent，交给轨道渐变去画。

滑块组件派生评分组件

评星是 range 的衍生组件：整块输入框用 mask 镂成 5 颗星，轨道铺满金色（等于全部点亮）， 滑块只留 1px 当定位点，用它的阴影把右侧盖成灰色，超出输入框的部分被 mask 裁掉，同样不需要 JS。

改 mask-size 的平铺宽度、输入框的宽高，就能得到不同大小、不同疏密的评分，参见第二个评分效果。

四、下拉框选择

支持 appearance: base-select 的内核（如 Chrome 135+）能把下拉面板一起自定义； 不支持的，就只改 select 本身，点开仍是系统默认的下拉。

支持 base-select 时，select 变成一个可控的按钮：箭头是 ::picker-icon， 下拉面板是 ::picker(select)，里面的每一项就是 option， 选中、悬停、禁用都能各给一套样式，展开收起还能用 @starting-style 加个淡入。

不支持时只能 appearance: none 后自己补箭头，所以 select 和选项的左右内边距要对得上： 面板里的 option 也是收起状态显示的那一行，两边写一样的 padding，文字才不会跳。
