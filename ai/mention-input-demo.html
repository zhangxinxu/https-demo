使用IMG元素作为标签节点演示案例

输入框里的文件名标签，真正的 DOM 是 <img> 元素： src 指向 1×1 透明 gif，图标和文字都由 CSS 背景图渲染。

支持图片、视频、文档
  1. 为什么用 img：它是 contenteditable 里的原子节点，光标只能落在它前后，Backspace 一次删掉整块，天然可拖拽、有 alt/title 描述，不需要 contentEditable=false 那一堆补丁。
  2. 视觉为什么在背景里：src 是透明占位图，类型图标是内联 SVG，文件名是 SVG <text>，二者都塞进 background-image，节点尺寸靠 JS 算好写进 width。
  3. 宽度为什么要量：背景图不会参与布局，所以先用 canvas 的 measureText 按展示字体量出文字宽度，再据此裁剪 SVG 背景、决定 img 宽度。
