使用IMG元素作为标签节点演示案例

输入框里的文件名标签，真正的 DOM 是 <img> 元素： src 就是文件名本身（SVG 图），类型图标画在右侧 padding 撑出的空白里。

支持图片、视频、文档
  1. 为什么用 img：它是 contenteditable 里的原子节点，光标只能落在它前后，Backspace 一次删掉整块，天然可拖拽、有 alt/title 描述，不需要 contentEditable=false 那一堆补丁。
  2. 图标为什么在背景里：src 已经被文件名占用，类型图标只能走 background-image；给 img 右侧留出 padding 当画布，图标就画在这块空白里，不用伪元素也不用额外子节点。
  3. 宽度为什么要量：SVG 图没有排版能力，先用 canvas 的 measureText 按展示字体量出文字宽度，再据此生成 SVG 的 width 和 img 的 width，两者一致才不会缩放变形。
